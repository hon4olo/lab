# Stress Case Inventory

Work through this list for any game with ads or progression. Each row is a moment where a normal UI decision becomes a trust decision.

## Failure

| Case | Question to answer |
|---|---|
| Repeated death on one level | Does the game offer help, or comment on the failure? |
| Trivial instant death | Is there a full game-over screen for a two-second run? There should not be |
| Unclear failure reason | Can the player tell what killed them? |
| Long run lost | Does the screen lead with what they achieved, or with the loss? |
| Fail during tutorial | Is failure even possible here? It usually should not be |

## Ads and money

| Case | Question to answer |
|---|---|
| Ad no-fill | Is the player told, and returned to play immediately? |
| Ad error mid-load | Is the UI unblocked and the flow continued? |
| Ad closed early | Is the absence of reward explained without blame? |
| Reward not granted after a completed ad | Is this logged? This is the worst bug in the category |
| Adblock detected | Is the game still fully playable? Is the notice non-accusatory? |
| Declining an ad | Does declining feel neutral, or punished? |
| Insufficient currency | Is the exact shortfall shown? |
| Purchase failed | Is it clear no money was taken? |

## Progress and system

| Case | Question to answer |
|---|---|
| Save failed | Does the game own the failure and say what still counts? |
| Progress lost | Is the scope of the loss stated precisely? |
| Offline | Can the player keep playing? |
| Tab hidden mid-run | Does the game pause and resume cleanly, once? |
| Performance stutter at a critical moment | Is there a graceful degradation path? |

## Attention and access

| Case | Question to answer |
|---|---|
| Popup overload after a level | How many modals stack before the player can act? |
| Mis-tap on a small screen | Is a destructive or paid action adjacent to a common tap? |
| Sound off | Is any critical feedback audio-only? |
| Colour-blind player | Is any critical distinction carried by colour alone? |
| Distracted player returning after 30 seconds | Can they tell what state the game is in? |

## How to use this

For each applicable row: write down the current copy, the current behaviour, and what the player most likely believes happened. The gap between the last two is the work.
