# Lens Groups

Use these groups to select the right perspectives for a review.

## Concept lenses

Use early:

- Essential experience
- Player
- Theme / resonance
- Toy
- Problem statement
- Risk
- Technology

## Prototype lenses

Use when playable:

- Core loop
- Control
- Feedback
- Goals
- Challenge
- Meaningful choice
- Skill vs chance
- Juiciness

## Systems lenses

Use when mechanics are expanding:

- Balance
- Economy
- Rewards
- Punishment
- Emergence
- Complexity
- Dominant strategy
- Progression

## Content lenses

Use when levels/world/story exist:

- Interest curve
- Surprise
- Curiosity
- World
- Character
- Space
- Story
- Indirect control

## Production lenses

Use near release:

- Playtesting
- Documentation
- Team
- Technology
- Profit
- Responsibility
- Accessibility
- Community

## Web portal priority order

For small web games, usually review in this order:

1. Essential experience
2. Toy
3. First-session player
4. Core loop
5. Control and feedback
6. Challenge/flow
7. Reward/progression
8. Interest curve
9. Balance
10. Monetization/responsibility
