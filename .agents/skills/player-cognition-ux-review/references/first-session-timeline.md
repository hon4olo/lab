# First-Session Timeline Review

Use this when auditing the first minute of a browser game.

## 0-3 seconds

Goal: Player knows what they can do.

Check:

- Is there a clear start state?
- Is the primary control obvious?
- Is the first interactable visible?
- Is any menu or popup delaying play?
- Is the camera framing useful?

Red flags:

- Intro text before interaction.
- Multiple buttons of equal importance.
- No visible objective.
- Required account/login/consent before gameplay unless unavoidable.
- Audio/visual splash that cannot be skipped.

## 3-10 seconds

Goal: Player performs one meaningful action.

Check:

- Has the player moved, aimed, shot, merged, collected, dodged, built, upgraded, or otherwise used the core verb?
- Did the action produce readable feedback?
- Did the game confirm success or failure?

Red flags:

- Player only navigates menus.
- Player reads rules but does not act.
- Core verb is still hidden.
- Failure happens before understanding.

## 10-30 seconds

Goal: Player understands a short-term goal and receives a reward or clear consequence.

Check:

- Is there a visible objective?
- Has the player seen a reward, danger, score change, progress bar, enemy reaction, collectible, upgrade, or level response?
- Is cause-and-effect clear?

Red flags:

- Progress is invisible.
- Feedback is too subtle.
- Reward is delayed.
- The player does not know whether they did well.

## 30-60 seconds

Goal: Player has a reason to continue.

Check:

- Is the next goal visible?
- Is a new variation introduced?
- Is there a sense of mastery, collection, score chase, unlock, survival, speed, or improvement?
- Is the player still in flow?

Red flags:

- Repetition without escalation.
- Meta systems before the core loop is fun.
- Monetization before meaningful play.
- Difficulty spike with no practice.
